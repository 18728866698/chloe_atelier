Dynamic Island· 灵动岛倒计时
点下面的按钮会自动运行你 iPhone 上的快捷指令，启动一个系统计时器——倒计时会显示在灵动岛和锁屏上，结束时系统强提醒。
首次使用需创建快捷指令（一次性，约 1 分钟）：
1. 打开 iPhone「快捷指令」App → 右上角 ＋ 新建
2. 底部搜索添加动作「接收来自快捷指令的输入」→ 类型选「文本」
3. 再添加动作「开始计时」→ 点「时长」→ 选「每次询问」或绑定「接收的输入」
4. 把快捷指令命名为 专注计时（和上面输入框一字不差）→ 完成
之后每次在房间页点「▶ 启动」，灵动岛立刻出现倒计时。
· 当前选择的专注时长（ 分钟）会自动传给计时器
· 建议再给快捷指令加一个「计时结束时播放提示音」动作
Cloud Sync· 跨设备数据同步
数据存在你的 GitHub 私有仓库里，手机 / 平板 / 电脑只要登录同一份配置就完全一致。只需要设置一次。
· Token 第一次需要去 GitHub 生成：github.com → 右上角头像 → Settings → Developer settings → Personal access tokens → Generate new token，勾选 Contents: Read and write 权限即可
· Token 只保存在本机浏览器里，不会上传到任何地方
· 打卡 / 错词 / 备考进度等文字数据全部同步；音频、视频文件不同步（设备本地各自选择即可）
